NIRF Automation - Web Deployment v20

Recommended: Render using Docker

1. Create a GitHub account/repository.
2. Upload ALL files from this folder to the repository root.
3. In Render, choose New > Web Service and connect the GitHub repository.
4. Choose Docker as the runtime/language if Render does not detect it automatically.
5. Deploy. The Dockerfile installs Python, app dependencies, and OCR on the cloud server.
6. After deployment, open the public Render URL. No Python is needed on the user's computer.
7. Test <your-public-url>/health. It should report version 20.0.

Railway alternative:
1. Push the same folder to GitHub.
2. New Project > Deploy from GitHub Repo.
3. Railway detects the Dockerfile automatically.
4. Settings > Networking > Generate Domain.

Important:
- Up to 100 PDFs are accepted by the application.
- Large 100-PDF jobs need enough cloud RAM/CPU and request time. If a low-resource/free plan times out, use a paid instance or process smaller batches.
- Uploaded files are processed by the web service; do not deploy publicly with sensitive documents unless your organization approves the hosting/privacy setup.
