# NIRF Automation v9

Supports Engineering, Pharmacy, Management and Overall templates.

- Up to 100 PDFs per batch.
- All institutions are written to one Excel workbook.
- Formula-only calculation proof remains in the cells.
- Dynamic program mapping supports UG/PG durations and PG Integrated.
- Engineering / Pharmacy: IPR totals for No. of Patents Published and No. of Patents Granted (sum of 3 calendar years).
- Management and Overall: EDP/MDP totals for number of programs, participants and annual earnings (sum of 3 financial years).
- Existing Engineering calculations remain unchanged.

Run `start_nirf.bat`, then open http://127.0.0.1:8000/
